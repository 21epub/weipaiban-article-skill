# 主题清单

先 `--recommend`（或用户指定），再读 `theme-{id}.md`。字号、边距、正文色范围见 [visual-system.md](../references/visual-system.md)。本表只帮选题，不要按「适配」列随机。

各主题文件末尾的「挑图气质」只提供 `styleAnchor` / `lightingHint`，用来在 AI 素材池里挑图。默认不出图。

选题：`python3 "$SKILL_DIR/scripts/pick_theme.py" --recommend --query "{用户原话}"`。用户确认后再 `--theme {id}` 锁定。

## 风格族谱

```
经典系
├── 摸鱼绿        → 清新杂志感
├── 红白          → 庄重编辑风
├── 石墨极简      → 理性灰阶 / 暖橙点睛
├── 留白禅意      → 东方呼吸感
├── 橄榄手记      → 内刊温度
└── 摸鱼票据      → 趣味卡片

趋势系
├── 新中式        → 宋式留白 / 水墨淡彩 / 竖排印章
├── 弥散光感      → 半透明浅卡 / 低饱和渐变
├── 暗黑霓虹      → 有彩色深底 / 荧光点缀
├── 杂志编辑      → 衬线大字 / 隐形网格
├── 拼贴手账      → 纸纹拼贴 / 胶带手感
├── 极简黑白      → 瑞士国际主义 / 近黑近白网格
├── 像素现场      → 浅纸阶梯色块 / 一格暖金
├── 浅蓝水彩      → 水色色条 / 宽行距
├── 靛蓝布标      → 布面明线 / 虚线针脚
├── 复古报刊      → 双线栏 / 版首印泥日期
├── 手绘绘本      → 挂旗短条 / 绘本暖纸
└── 青春校园      → 活页虚线 / 黑板青编号
```
